# 🤖 AI Career Agent

An AI-powered career guidance application that helps users understand their current skills, identify career skill gaps, analyze resumes, and receive personalized learning recommendations.

# ✨ Features

- 🎯 Career goal selection
- 🧠 AI-powered career skill-gap analysis
- 📊 Skill match score
- ✅ Matched skills detection
- ❌ Missing skills identification
- 📚 Personalized learning recommendations
- 🛣️ Beginner-friendly learning roadmap
- 📄 Resume upload and analysis
- 🔍 Resume skill detection
- 💡 Additional industry skill recommendations
- 🎨 Light, colorful and responsive dashboard UI

# 🧩 Career Skill Analysis

The application compares the user's current skills with the required skills stored in the career database.

The analysis clearly separates:

Database Required Skills

These are the authoritative skills required for the selected career.

Additional Recommendations

These are useful industry skills recommended by the AI but are not treated as database-required skills.

Learning Roadmap

A practical learning sequence that guides the user from foundational skills to advanced industry skills.

The roadmap follows this general order:

1. Foundational skills
2. Practical development skills
3. Deployment and production skills
4. Advanced industry skills

# 📊 Skill Match Score

The application calculates a skill match percentage based on the user's current skills and the required career skills.

The score is displayed clearly near the beginning of the AI career analysis.

# 📄 Resume Analysis

Users can upload their resume and analyze it to identify relevant skills.

The detected skills are displayed in the dashboard and can be used as part of the career analysis process.

# 🧠 AI Recommendations

The AI provides:

- Skills the user already has
- Skills the user is missing
- Skills they should learn first
- A practical learning order
- A phased learning roadmap
- Additional industry recommendations

# 🖥️ Dashboard

The dashboard contains:

- Career selection
- Current skills input
- Career analysis
- Resume upload
- Resume analysis
- AI recommendations
- Skill match visualization
- Learning roadmap

The interface uses a light, attractive visual design with soft gradients and responsive layouts.

# 🚀 Running the Project

Start the Django development server:

python manage.py runserver

Then open the application in your browser using the local Django server address.

# 📁 Project Purpose

The purpose of this project is to provide users with an intelligent career guidance system that connects their existing skills with the skills required for their target career.

Instead of simply listing missing skills, the application provides a practical path for learning them.
